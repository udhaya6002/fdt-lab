## Running the HTML pages
Open the HTML files directly in a browser:
- Bookstore: `FED-Lab-Manual/Bookstore-Website/home.html`
- CSS: `fontstyles.html`, `bg_image.html`, `bg_repeat.html`

## Running an Angular project
```bash
cd Calculator-App      # or any other Angular folder
npm install            # only needed the first time
npm start              # runs ng serve and opens http://localhost:4200
```

Login for **Experiment-4-Auth-Login**: username `admin`, password `1234`.
